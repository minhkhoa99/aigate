## Quyết định cần duyệt (mặc định tôi đề xuất)
1. **Đơn vị ghi.** Mỗi lần gọi upstream một event: thành công, lỗi, hoặc stream bị huỷ.
   - Có `requestId` để SP24b gom các attempt của cùng một request.
   - 9router chỉ ghi lần cuối và bỏ dòng 0 token, nên tỷ lệ lỗi luôn là 0. Spec cần "lỗi %".
2. **Phạm vi lane.** Chat lane: OpenAI Chat, Anthropic, Responses, Gemini, và cả combo/fusion (mỗi member là một event). Media lanes (embeddings, image, TTS, STT, search, fetch) để SP24b.
3. **Không có usage.** Khi upstream không trả usage hoặc stream bị huỷ: ước lượng như 9router (input từ request, output = số ký tự đã phát / 4), đánh dấu `estimated`.
4. **Không có giá.** Model chưa có giá thì cost = `null`, UI hiện "chưa có giá". 9router ghi $0 mãi mãi.
5. **Timezone.** Biến env `AIGATE_USAGE_TIMEZONE` (IANA), mặc định là timezone máy lúc khởi động. Timezone được ghi rõ trong mọi response.
6. **Retention.** Events giữ 90 ngày (`AIGATE_USAGE_RETENTION_DAYS`), dọn mỗi giờ. Bảng daily giữ 400 ngày.
7. **Pricing.** Bảng mặc định copy dữ liệu từ `open-sse/providers/pricing.js`, gồm 3 tầng: provider → model → pattern. Alias `gh` ánh xạ sang `github`. Override lưu trong bảng riêng. Không làm `/api/pricing/defaults` (route chết trong 9router); `GET /api/pricing` đánh dấu từng giá là override hay mặc định.

## Implementation steps
1. **Matrix và contract.**
   - Gắn nhãn thêm quyết định AIGate vào các mục usage/pricing.
   - Viết `docs/contracts/usage.md`.
   - Thêm SP24a/b/c vào task board.
2. **Engine.**
   - `pricing.ts`: bảng giá mặc định, `pricingFor(provider, model, overrides)`, `costOf(usage, price)`.
   - Test công thức: cache, reasoning, thiếu giá.
3. **DB (migration 0022).**
   - `usage_events`: id, at, request_id, provider, model, connection_id (FK set null), api_key_id (FK set null), endpoint, status (`success` | `error` | `aborted`), error_code, token × 5, estimated, cost (nullable), latency_ms, ttft_ms. Index theo `at` và theo `provider, model`.
   - `usage_daily`: khoá (day, provider, model, connection_id, api_key_id, endpoint); đếm requests, errors, token × 5, cost, số request chưa có giá. Upsert cộng dồn.
   - `pricing_overrides`: (provider, model) PK, 5 mức giá, updated_at.
4. **Server, module `usage`.**
   - `UsageRecorder`: queue tối đa 10 000 event, flush mỗi 1 s hoặc khi đủ 200, trong một transaction (insert events + upsert daily). Đầy thì bỏ event cũ nhất và đếm; ghi lỗi thì đếm. Flush lần cuối khi shutdown.
   - Live: đếm request đang chạy theo model/account (watchdog 60 s), ring 50 request gần nhất.
   - `UsageRepository`: summary và chart bằng SQL GROUP BY.
     - Kỳ `24h`/`today` đọc events theo giờ.
     - Kỳ `7d`/`30d`/`90d`/custom đọc daily; custom tối đa 400 ngày.
     - Tên provider, account, key lấy qua join.
   - API (session):
     - `GET /api/usage/summary?period=|from=&to=`
     - `GET /api/usage/chart?period=`
     - `GET /api/usage/export.csv?period=`
     - `GET /api/usage/stream` (SSE: gửi ngay khi kết nối, debounce 250 ms sau mỗi flush, ping 25 s, tối đa 16 client)
     - `GET /api/pricing`, `PATCH /api/pricing`, `DELETE /api/pricing?provider=&model=`
     - Validate như 9router: đúng 5 field, số ≥ 0 và hữu hạn.
   - Hook vào `ChatLane`:
     - Ghi usage của response non-stream.
     - Ghi usage stream khi kết thúc hoặc bị huỷ, kèm TTFT.
     - Ghi lỗi của mỗi attempt.
     - Ghi `apiKeyId` từ bước kiểm key.
     - Việc ghi không bao giờ chặn hay làm hỏng response.
5. **Web.**
   - `/traffic/usage`:
     - Kỳ trong URL (Today, 24h, 7d, 30d, 90d, Custom).
     - 4 metric.
     - Chart token xếp chồng theo provider và đường cost theo ngày/giờ.
     - Bảng provider × model: requests, in, out, cached, $, lỗi %.
     - Request đang chạy và gần nhất (SSE).
     - Nút Export CSV.
     - Cảnh báo khi writer drop hoặc ghi lỗi.
   - Modal Pricing: tìm model, sửa 5 mức, reset model/provider/tất cả.
   - Mã lỗi mới đi qua `errors.ts`.
6. **Tài liệu.** `API_UI_MAP.md`, `CLAUDE.md`, handoff, graph.
