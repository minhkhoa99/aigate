# SP24b: request detail (metadata + attempts), usage của media lanes, màn Requests

## Context
- SP24a (`d45e04b`) đã ghi mỗi lần gọi upstream thành một dòng `usage_events`, có `requestId` chung cho các attempt của cùng một request. Tuy vậy vẫn chưa có:
  - một dòng cho từng request của client: model client yêu cầu (tên combo, hoặc model trần), kết quả cuối, HTTP status trả client, tổng latency, TTFT;
  - usage của các media lane (embeddings, image, TTS, STT, search, fetch, video);
  - API và UI cho request.
- Matrix: `usage.request-details-buffered-persistence`, `usage.request-details-api-redaction`, `usage.providers-distinct-api`, `usage.request-field-trace-order`.
- Quyết định đã có (user, 2026-09-30): chỉ lưu metadata + attempts, không lưu body.
- 9router:
  - request detail tắt mặc định (`enableObservability: false`), lưu body cắt 5 KB, API luôn che body, tối đa 1000 dòng;
  - phân trang `page` / `pageSize` 1–100;
  - list provider lấy bằng DISTINCT trên bảng request detail.
- Spec §UI 10: list ảo hoá, cursor pagination, lọc lỗi / provider / model / có fallback; trang chi tiết là timeline từng attempt.

## Quyết định cần duyệt (mặc định tôi đề xuất)
1. **Luôn bật, không opt-in.** Bảng `usage_requests` luôn ghi, dùng chung buffered writer và retention của events (90 ngày).
   - 9router tắt mặc định vì lưu body chứa hội thoại. AIGate chỉ lưu metadata, nên lý do đó không còn.
   - Chưa có request nào thì trang vẫn hiện trạng thái rỗng.
2. **Media lanes.** Ghi event + request cho `/v1/embeddings`, `/v1/images/generations`, `/v1/audio/speech`, `/v1/audio/transcriptions`, `/v1/search`, `/v1/web/fetch`, `/v1/videos/*`.
   - Token lấy từ `usage` của upstream nếu có (embeddings, một số image); không có thì để 0.
   - Cost là `null` (unpriced), trừ khi user đặt override cho model đó.
   - TTS ghi theo từng connection đã thử (xoay tài khoản), giống chat.
3. **Phân trang bằng cursor** thay cho page/pageSize của 9router (spec: không endpoint nào trả dữ liệu không giới hạn).
   - `limit` tối đa 100.
   - Cursor là cặp `(at, id)` mờ, mã hoá base64url.
4. **Bộ lọc.**
   - Chỉ lỗi (gồm error và aborted), provider, model, endpoint, có fallback (số attempt > 1), khoảng thời gian.
   - Danh sách provider/model cho bộ lọc lấy DISTINCT trên `usage_daily` trong 90 ngày, tối đa 500 mục.
5. **Không có tab body.** Trang chi tiết chỉ có metadata và timeline; mọi mục khả thi của spec §23 đều được hiện. Không có trace id riêng: `requestId` chính là id trả trong header `x-request-id`.

## Implementation steps
1. **Matrix + contract.** Ghi quyết định vào 4 mục matrix trên; viết phần "Requests" trong `docs/contracts/usage.md`; cập nhật task board.
2. **DB (migration 0023).** Bảng `usage_requests`:
   - id = requestId, at, endpoint, requested_model, api_key_id, stream;
   - status (`success` | `error` | `aborted`), http_status, error_code;
   - attempts, final_provider, final_model, final_connection_id;
   - token × 5 (tổng các attempt), cost (tổng, null nếu có attempt unpriced và không có attempt nào có giá), latency_ms, ttft_ms.
   - Index theo `at` và theo `status, at`.
3. **Server.**
   - `UsageRecorder.request(row)` dùng chung queue, flush trong cùng transaction. Tổng token/cost cộng từ các event cùng requestId còn trong batch; request đến trước event thì cộng khi flush.
   - `ChatLane.serve` và từng media handler ghi một request row trong `finally`, với HTTP status và mã lỗi cuối cùng.
   - Media handler ghi event qua helper `meterMedia`.
   - `SpeechLane` ghi event mỗi lần thử một connection.
   - `RequestsController`:
     - `GET /api/requests?cursor=&limit=&status=&provider=&model=&endpoint=&fallback=&from=&to=` → `{ items, nextCursor }`
     - `GET /api/requests/filters` → `{ providers, models, endpoints }`
     - `GET /api/requests/:id` → `{ request, attempts }`, 404 `NOT_FOUND`
   - Tên hiển thị lấy qua join như summary.
4. **Web.**
   - `/traffic/requests`:
     - Bảng: time, model yêu cầu, provider cuối, account, status (pill + mã), attempts, TTFT, latency, tokens, cost.
     - Bộ lọc trong URL.
     - Nút "Load more" theo cursor.
     - Bảng giới hạn 500 dòng trong trang (ảo hoá để sau nếu cần).
   - `/traffic/requests/:id`:
     - Metric: latency, TTFT, tokens, cost.
     - Timeline attempt (provider / account / status / lỗi / latency).
     - Metadata có Copy request id.
     - Warning "không lưu body".
   - Route động `/traffic/requests/<id>` thay route cứng `request-123`.
   - Mã lỗi đi qua `errors.ts`.
5. **Tài liệu.** `API_UI_MAP.md`, `CLAUDE.md`, handoff, graph.
