# Core dashboard localization — SP28

EN/VI is browser presentation only: two static JSON catalogs, one React locale
provider, native Intl and localStorage `aigate-language`. Missing/invalid
preferences fall back to en; denied storage leaves selection usable in memory.
`html lang` follows the preference, including standalone Auth. No locale API,
database field, export key, dependency, network translation or cross-tab sync.

Scope: shell/navigation/search; login/welcome/callback; General/Auth/Developer;
Overview; owned shared defaults/errors/core notices. SP32 extends Media
Providers and Voice Browser; SP33 extends Endpoint & Keys; SP34 extends Routing
Combo and Capacity editors; SP35 extends Token Saver; SP36 extends Quota;
SP37 extends Usage analytics and Pricing; SP38 extends Requests list/detail;
SP39 extends the Developer Console; SP40 extends Proxy Pools and Deploy Wizard.
Other feature pages and raw server/provider diagnostics
remain English/verbatim. Preserve URLs, query
keys, model/provider IDs/names, error codes, environment names and filenames.
`IMPORT` stays literal. Settings export still carries its 16 server keys.

Catalog keys/placeholders must match. Missing VI text falls back to English;
unknown keys/missing parameters remain visible markers, never undefined or HTML.
Interpolation is one pass over the fixed template, with own-property lookup.
Only supported wire-code advice lives under `errors.*`; internal formatting
variants/fallbacks use `errorAdvice.*`, so unknown API codes cannot select them.

Format with en-US/vi-VN, preserve USD, precision and the usage timezone. Language
changes do not recreate router/query providers, refetch, reopen SSE, reset
form/tab/import state, replay mutations or restart toast dismissal. Inline
errors and localized notices retain inputs for render-time resolution; legacy
string notices remain supported. One toast, existing six-second lifetime.

Spec/plan: `docs/superpowers/specs/2026-10-06-sp28-core-ui-i18n-design.md` and
`docs/superpowers/plans/2026-10-06-sp28-core-ui-i18n.md`. Native locale/errors/SSE
checks verify catalog, formatting, diagnostics, real component rendering and
existing stream-reader boundaries. Isolated browser acceptance passed on
2026-10-08: storage denial, state/payload preservation, toast/SSE lifetimes,
raw diagnostics and EN/VI layout at 1440/929/390px. See the handoff for actual
mock boundaries and evidence. This is core-scope acceptance, not whole-dashboard
localization, baseline visual regression or full accessibility/performance certification.

SP32 follows the same `LocaleProvider` and static catalogs. Media kind labels,
route/account status, voice controls, empty/error/help text, gender labels and
language/region display names use the selected EN/VI locale. Provider/model/
voice IDs and names, endpoint paths, error codes, raw diagnostics and the
fixed English preview sample remain literal. A locale switch renders text
without changing voice query keys, filters, selected model/provider, preview
payload or playback. Copy/preview toasts resolve at render time. The existing
200-row voice limit, user-triggered preview, abort and object-URL cleanup stay
in force. SP32 adds no server API, dependency or storage key.

SP33 extends owned copy to Gateway Endpoint & Keys. The selected client
protocol and one-time key modal stay mounted across a locale change; the
static example URLs, commands, request bodies, header names, API key value,
stable error codes and raw diagnostics remain literal. Readiness, key states,
controls, dates and notices use the selected locale. See `endpoint-setup.md`.

SP34 extends owned copy to Routing Combo list/create/edit and Capacity adapter.
Selected tab, typed drafts, duplicate validation and pending saves survive an
EN/VI switch. Combo/model IDs, API codes and permitted raw diagnostics stay
literal. `Test` still makes one real provider request only when clicked; locale
changes never probe or replay a mutation. See `routing-editor-i18n.md`.

SP35 extends owned copy to Token Saver. Stage names, settings values, the
opt-out header and URLs stay literal. Headroom draft and pending settings or
PXPIPE operations remain mounted across EN/VI. A PXPIPE status read error
shows Retry and never implies that installation is needed. See
`token-saver-ui-i18n.md`.

SP36 extends owned copy to the Quota dashboard. Account, plan and vendor
window names stay literal; values retain USD and use the chosen locale.
Changing language neither refetches quota nor replays manual refresh. Missing
vendor balances and failed reads remain unknown. See `quota-ui-i18n.md`.

SP37 extends owned copy to Usage analytics, charts and Pricing. The period,
custom dates, color slots and pricing draft stay mounted across EN/VI. The
server's usage timezone still defines buckets, while native Intl formats
labels and USD for the browser locale. Live SSE and pending price saves are
not reopened or replayed by language changes. See `usage-ui-i18n.md`.

SP38 extends owned copy to Requests list/detail. URL filter values, cursor
pages and request metadata stay mounted and literal across EN/VI. Failed
filter/page/detail reads show their code, permitted diagnostic and Retry;
loaded rows stay visible after a next-page failure. See
`requests-ui-i18n.md`.

SP39 extends owned copy to the Developer Console and its closed gate. Level
filter values, metadata events, Pause/SSE and pending Clear remain mounted
across EN/VI. A failed read shows code/diagnostic/Retry; a failed Clear keeps
events and shows code/diagnostic. See `console-ui-i18n.md`.

SP40 extends owned copy to Proxy Pools and the Deploy Wizard. Pool/rotation
IDs, URLs, wire strategies and credential payloads remain unchanged. Mounted
drafts and pending mutations survive EN/VI without refetch or replay; failed
reads show code/diagnostic/Retry. See `proxy-pools-ui-i18n.md`.
